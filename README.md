# 🏛️ כנסת AI (knAIset)

סימולציה של דיון במליאת הכנסת. **כל ראש מפלגה הוא סוכן Claude נפרד**, עם הקונטקסט, הזיכרון והמחשבות שלו.
המשתמש מציע נושא, הסוכנים חוקרים אותו בעצמם ברשת, מתווכחים לפי תור עם **מקל דיבור**, שומעים זה את זה
וחושבים בשקט, צועקים קריאות ביניים, ובסוף **מצביעים**.

> ⚠️ זו סימולציה סאטירית שנוצרת על ידי בינה מלאכותית. הנאומים לא אמיתיים, ואין לייחס אותם לאנשים האמיתיים.

## הרצה

```bash
npm install
cp .env.example .env          # ואז להכניס ANTHROPIC_API_KEY
npm start                     # http://localhost:3000
```

אפשר גם בלי מפתח: `npm run demo` מפעיל **מצב דמו** עם תוכן מוכן מראש. הוא טוב לבדיקת ה-UI ומנגנון התורות.

## איך זה עובד

```
נושא מהמשתמש
   │
   ▼
① מחקר (במקביל): כל סוכן מריץ web_search ו-web_fetch לפי docs/RESEARCH_GUIDE.md
                  ובונה "תיק מודיעין" פרטי (נשמר במטמון לפי נושא ותאריך)
   │
   ▼
② דיון, לולאה:
   ├─ בחירת מחזיק המקל: מי שעוד לא דיבר בסבב, מי שהרים יד (דחיפות), מי שפנו אליו ישירות,
   │                     עם קנס על דיבור חוזר, כדי ששני יריבים לא יחזיקו את המקל לבד
   ├─ 🎤 הדובר (Opus): מקבל את כל הפרוטוקול, התיק שלו והמחשבות הפרטיות שלו,
   │      יכול לחפש עובדה אחת או שתיים, ומדבר דרך הכלי speak:
   │      {נאום, למי הוא פונה, טון, עמדה, מחשבה פנימית, מוכן להצביע?, הצעת נוסח}
   ├─ 👂 כל השאר (Haiku, במקביל) מקשיבים: מחשבה פרטית, אימוג'י, הרמת יד, דחיפות וקריאת ביניים.
   │      שתי קריאות הביניים הכי חזקות נכנסות לפרוטוקול, וכולם שומעים אותן.
   └─ עצירה: המשתמש לוחץ "להצבעה", או 60% מהדוברים האחרונים ביקשו להצביע, או נגמרו התורות
   │
   ▼
③ הצבעה: המזכירות מנסחת הצעת החלטה (או שהמשתמש כותב אחת), כל סוכן מצביע בעד, נגד או נמנע
         עם הסבר. התוצאה נספרת לפי מנדטים וגם לפי ראשי מפלגות.
   │
   ▼
④ סיכום: כתבה קצרה על הדיון ו"רגעים בין-אישיים" שנשמרים ב-data/dynamics.json
         ונכנסים לזיכרון של הסוכנים בדיון הבא (מי העליב את מי, אילו בריתות נוצרו)
```

### הקונטקסט של כל סוכן
- **קבוע** (`mks/<id>.md`): רקע, אידיאולוגיה, סגנון דיבור, ביטויים, הומור, טריגרים, התנהלות בדיון ורמזי חיפוש.
  כל פרט שלא בטוח מסומן ב-⚠️, ואז הסוכן מאמת אותו בעצמו.
- **יחסים** (`mks/relationships.json`): 32 זוגות עם רמת מתח, תקציר, ואיך כל צד מדבר על השני.
- **דינמי**: מה שהסוכן מוצא בחיפוש בתחילת הדיון ובמהלכו. המדריך `docs/RESEARCH_GUIDE.md` מסביר
  איך לחפש בוויקיפדיה, בחדשות בעברית, באנגלית ובערבית, ב-X (דרך ציטוטים בחדשות), באתר הכנסת,
  בכנסת הפתוחה, בממשק ה-OData של הכנסת ובסקרים.
- **זיכרון**: מחשבות פרטיות מכל הדיון, וזיכרונות מדיונים קודמים.

### ה-UI
- **מליאה** בחצי עיגול, לפי הגושים. מקל הדיבור 🎤 עובר בין המושבים, ויש אנימציות של חיפוש, הרמת יד, אימוג'י וקריאות ביניים.
- **פרוטוקול** חי עם טון, עמדה, למי פונים, מקורות ו-🧠 מחשבות פרטיות (אפשר להסתיר).
- **שליטה של היו"ר (המשתמש)**: השהיה, הערת יו"ר שכל הסוכנים שומעים, העברת המקל לח"כ מסוים
  (לחיצה על המושב), וקריאה להצבעה עם נוסח משלכם.
- **לוח הצבעה** עם פס מנדטים ו"חותמת" של התוצאה.
- **ניתוח הדיון**: מפת "מי תקף את מי", ציר זמן לפי טון, זמן דיבור, שינויי עמדה, סטטיסטיקות ו**שידור חוזר** של כל הדיון.
- היסטוריה של כל הדיונים (`data/sessions/`).

## הגדרות (`.env`)
| משתנה | ברירת מחדל | |
|---|---|---|
| `MK_MODEL` | `claude-opus-5-5` | המודל של הח"כים והיו"ר |
| `REACTION_MODEL` | `claude-haiku-5-5` | ההקשבה אחרי כל נאום (המון קריאות קצרות) |
| `SPEECH_EFFORT` / `RESEARCH_EFFORT` | `medium` | עומק החשיבה |
| `REACTIONS` | `on` | `off` מכבה את שלב ההקשבה |
| `CONCURRENCY` | `4` | כמה קריאות API רצות במקביל |
| `MOCK` | `0` | מצב דמו |

בקריאות ל-Opus מוגדר גם `fallbacks: "default"`. אם המודל מסרב לבקשה, הבקשה רצה שוב אוטומטית על מודל חלופי.

**עלות משוערת** (הערכה גסה, לא מדידה): דיון של 11 ח"כים ו-22 נאומים יעלה כמה דולרים. רוב העלות היא המחקר
(חיפושים ותוצאות ארוכות) והנאומים. המחקר נשמר במטמון, כך שדיון חוזר על אותו נושא באותו יום זול יותר.
כדי לחסוך: לקצר את `maxTurns`, להוריד משתתפים, או `REACTIONS=off`.

## מבנה

```
mks/                 פרסונות (md), רשימה (roster.json), יחסים (relationships.json)
docs/RESEARCH_GUIDE.md   איך הסוכנים מחפשים מידע דינמי (נטען לתוך הפרומפט)
src/agent.ts         סוכן ח"כ: research / speak / react / vote
src/debate.ts        המשחק: מקל דיבור, תורות, הצבעה, אירועים
src/chair.ts         היו"ר הניטרלי: ניסוח הצעה וסיכום
src/prompts.ts       כל הפרומפטים
src/llm.ts           Anthropic SDK: streaming, pause_turn, structured outputs, fallbacks
src/mock.ts          מצב דמו
src/server.ts        Express + SSE
public/              ה-UI (HTML/CSS/JS, בלי build)
```

## הוספת ח"כ
1. מוסיפים רשומה ל-`mks/roster.json`.
2. כותבים את `mks/<id>.md` באותו מבנה כמו האחרים.
3. אפשר להוסיף זוגות ל-`mks/relationships.json`.
